## 참조에서 제품으로 옮긴 부분

- 이론/씨앗과 정답을 유지했다. flow의 표시 문자열은 WORDS와 한국어 조사 변환을 거친다.
- 원본 onOk의 fx 직후 hear 호출은 새 듣기의 전체 취소가 효과음을 끊을 수 있다. 제품은 이전 재생을 정리한 hear(.24) 다음 맞음 잡음을 예약한다.
- 레이아웃 y(p)의 p는 절대 오선 자리28~42다. 설명에 쓰이는 층1~15를 그대로 전달하지 않는다.
- 복습열은 마지막 마감 운행을 내기 직전에 확정한다. 마감에서 처음 발생한 ◐는 최초 성적에 반영하며 앞선 복습열에는 들어가지 않는다.
- SaveV1에 복습 위치·발견 장면·당일 새 카드 필드를 선택 필드로 추가했다. 없는 필드는 기본값으로 복원한다.
- 자유 실험실의 화음·가리기 설정은 운행 카드의 버튼으로 연다. 작은 화면에서도 원래 다섯 줄 무대 높이를 확보한다.
- 실기기·청감·강사·학습자 검수는 자동 검사와 함께 각각의 상태를 기록한다.

## 회귀 수정

- 실험실 모델 ID에 화음 이름을 넣어 3음→4음→3음 전환 시 음 단추를 다시 만든다. 변경 전에 이전 소리를 정리한다.
- 개발용 해시 운행은 메모리에서 실행하며 저장·보상에 반영하지 않는다. SPIKE id 저장으로 기존 기록이 초기화되는 회귀를 막았다.
- 실험실 선택창의 위·아래 키는 선택창 기본 동작을 사용한다.
- 초기화 확인 단계는 설정을 나가거나 초기화한 뒤 해제한다.
